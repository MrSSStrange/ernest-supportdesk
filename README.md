# Ernest SupportDesk

Очередь обращений для первой линии поддержки медицинских организаций.

**Демо:** https://mrssstrange.github.io/ernest-supportdesk/

## Что есть в проекте

- поиск и фильтрация обращений;
- приоритеты, статусы и контроль SLA;
- назначение исполнителя в тестовых данных;
- отдельная страница обращения;
- быстрое создание новых заявок;
- сохранение изменений в `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Стек: React, TypeScript, React Router и Vite. Серверной части нет, данные для демонстрации вымышлены.
